# FC26 Player Value Analyzer

## Overview

This project analyzes player data from FC26 to identify undervalued transfer targets using a custom player value metric. The program cleans player data, calculates valuation scores, and visualizes player performance to support data-driven recruitment decisions.

## Technologies

- Python
- Pandas
- Matplotlib

## Skills Demonstrated

- Data cleaning
- Exploratory data analysis
- Feature engineering
- Data visualization
- Python programming

## Key Features

- Custom player value metric
- Automated player rankings
- Performance visualizations
- Transfer analysis
